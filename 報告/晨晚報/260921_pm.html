⚠️ 警報

95夜跑真因定位完成：不是 launchd 掉了，是 Mac 03:30 關機＋macOS 26 legacy launchctl 靜默失效

今早急救包本身跑成功並驗出真因：
① agent 一直都在載入中 → 連 10 晚零 log 不是 plist 掉了，是 Mac 在 03:30 是關機的（launchd 只對睡眠補跑，關機整段跳過）＝ 9/18 加的多時段 plist 正好對症。
② 更深的坑：這台是 macOS 26（Darwin 25），legacy launchctl load / start 會 exit 0 卻什麼都沒做——實測 load ✅ start ✅、WatchPaths 踢下去沒反應、十分鐘零 log、錯誤檔停在 7/11。
已把急救包改用新版 domain 指令 bootout / bootstrap gui/$UID / kickstart -k（失敗才退 legacy），並加自我驗證：啟動後等 25 秒確認 log 真的產生，沒有就直接開 Terminal 保底。
現況：框架/.runner_force 旗標還在（07:38 建立、未被消耗），log 仍停 09-11 ＝ 舊版 plist 還裝在上面，要用新版急救包再按一次。
教訓已落頁：exit 0 不等於有做事，排程類動作一定要驗到產物層。
